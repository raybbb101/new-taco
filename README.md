# NEW TACO（ニュー・タコ）

GameSir Pocket Taco（スマホを差し込むと画面の上側だけ見えるコントローラー）向けのゲームコレクション。TACO シリーズのバージョン4（仮の名前）です。

**遊ぶ:** https://raybbb101.github.io/new-taco/
（スマホの Chrome で開いて「アプリをインストール」または「ホーム画面に追加」すると全画面で遊べます。オフラインでも遊べます）

## 入っているゲーム

| ゲーム | ジャンル | 内容 |
|---|---|---|
| NONO ATELIER（ノノグラム・アトリエ） | パズル | 数字をヒントにマスをぬってドット絵を完成させるノノグラム。**73まいの絵・317問**。とくと絵に色がつく |
| LUCKY OCTO（ラッキーオクト 〜海底カジノ〜） | ローグライク | ポーカーの役をつくって「チップ × 倍率」で目標スコアをこえるカードローグライク。海のなかまを集めて8夜を勝ちぬく＋エンドレス |

### NONO ATELIER

| 難しさ | 形 | 数 |
|---|---|---|
| ★ かんたん | 1まいの絵（5×5・10×10） | 40問 |
| ★★ ふつう | 4ピース（2×2）で 20×20 の絵 | 15まい / 60問 |
| ★★★ むずかしい | 9ピース（3×3）で 30×30 の絵 | 10まい / 90問 |
| ★★★★ マスター | 16ピース（4×4）で 40×40 の絵 | 8まい / 127問 |

- 難しくなるほど絵がこまかく、最後は風景のドット絵（月夜の湖・夕焼けの海・富士と五重塔・海の底・オーロラ・夏祭り・宇宙・タコの王国）
- すべての問題は「ロジックだけで解ける」ことをソルバーで確認ずみ（必要なときだけ、はじめから見えているマスがある）
- 「かんたん」で5まい、「ふつう」「むずかしい」で2まいずつ絵を完成させると、次の難しさがひらく
- まちがいを知らせる／そろった列に自動で× はせっていで ON/OFF
- とちゅうのパズルは自動でセーブ

### LUCKY OCTO

- 1夜に3つのテーブル（小・大・ぬし）。8夜目の「深海の王」をたおせばクリア、そのあとエンドレス
- 海のなかま 41種（パッシブ効果）、おふだ 19種（カードを強化・変化）、星のカード（役のレベルアップ）、チケット 10種、ぬし 14種、デッキ 4種
- カードの強化 8種（真珠・サンゴ・ガラス・金貨・四つ葉・鉄・虹・石）、エディション 3種（キラ・ホロ・虹色）
- 夜のはじめで自動セーブ（「つづきから」で再開）

## そうさ

ボタンの説明は **メニュー → せってい（または「そうさ」）** と、各ゲームのポーズ（START）から見られます。遊んでいる画面はゲームだけにしています。

| | NONO ATELIER | LUCKY OCTO |
|---|---|---|
| 十字 | カーソル | ←→ カード / ↑ なかま・おふだ |
| A | ぬる（おしたまま連続） | カードをえらぶ |
| B | ×をつける（連続） | えらんだのをはずす |
| X | ヒント（1列教える） | 役を出す |
| Y | ひとつもどす | すてる |
| L1 / R1 | – | ならべかえ / 役の一覧 |
| SELECT | 絵の全体を見る（おしたまま） | デッキを見る |
| START | ポーズ | ポーズ |

PC のキーボード: 十字=矢印キー A=X B=Z X=S Y=A L1=Q L2=W R2=E R1=R START=Enter SELECT=Shift

## 画面

- 240×320 ドットを 2倍で描き、文字や細い線は 2倍の細かさ（ドット絵フォント DotGothic16）
- ゲームボーイ風ではなく、ふつうのゲームアプリ寄りのあざやかな色
- Pocket Taco で隠れない上側にだけ表示。見える範囲は「せってい」で調整（**初期値 64%**）

## ファイル

- `engine.js` — 共通エンジン（入力・ドットフォント・チップチューン・パーティクル・ポーズ・シャープ拡大）
- `launcher.js` — 起動画面・カートリッジのメニュー・せってい・そうさ説明・ボタンテスト
- `games/nono-core.js` — ノノグラムのしくみ（ドット絵の描き方・ライン・ソルバー・ピース分け）
- `games/nono-art1〜4.js` — 絵のデータ（難しさごと）
- `games/nono.js` — ノノグラムの画面
- `games/octo-sprites.js` / `octo-data.js` / `octo.js` — ラッキーオクトのドット絵・データ・画面
